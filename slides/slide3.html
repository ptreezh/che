Methodology

Three Cognitive Types

Critical Agent
Skeptical analyst, challenges assumptions, identifies logical fallacies
Awakened Agent
Self-aware, questions premises, explores alternative perspectives
Standard Agent
Baseline behavior, conventional reasoning, typical responses

Experimental Design

Population: 30 agents per generation, 15 generations

Models: gemma3, glm-4.7-flash, qwen3-coder, gpt-oss

Tasks: False premise detection, reasoning challenges

Metrics: Shannon entropy, Cohen's d, correlation analysis
