## 实验中监控（In-experiment Monitoring）

### 实时检查点

每2代记录以下指标：

| 检查项 | 正常范围 | 异常阈值 | 处理措施 |
|--------|----------|----------|----------|
| 平均分 | 5.0-9.0 | <3.0 或 >10 | 暂停检查 |
| 标准差 | 0.05-0.5 | >1.0 | 标记审查 |
| Shannon熵 | 0.5-1.5 | <0.3（多样性崩溃） | 记录警告 |
| 运行时间/代 | <30分钟 | >60分钟 | 检查超时 |

### 每代自动记录

- [ ] 检查点文件已生成（checkpoint_gen{N}.json）
- [ ] JSON格式有效（可读可解析）
- [ ] 关键字段完整：
  - [ ] generation
  - [ ] mean_score
  - [ ] model_distribution
  - [ ] role_distribution
  - [ ] shannon_entropy_models
  - [ ] shannon_entropy_roles

### 异常处理流程

**情况1：分数异常（<3或>10）**
```
1. 立即停止实验
2. 检查最后一代的代理配置
3. 查看错误日志
4. 若为系统性错误，重启该组实验
5. 若为随机异常，记录后继续
```

**情况2：多样性崩溃（Shannon熵<0.3）**
```
1. 继续运行（这是科学现象）
2. 详细记录崩溃过程
3. 最终报告中讨论
```

**情况3：运行超时**
```
1. 检查Ollama服务状态
2. 检查网络连接
3. 考虑降低并发数
4. 记录延迟原因
```

## 实验后验证（Post-experiment Validation）

### 1. 数据完整性检查 ✅

- [ ] **文件数量**: 6个组结果文件 + 1个汇总文件 = 7个文件
- [ ] **文件命名**: 符合`group_{A-F}_result.json`格式
- [ ] **文件大小**: 每个>1KB（非空文件）
- [ ] **JSON有效性**: 所有文件可解析

### 2. 数据一致性检查 ✅

- [ ] **代数连续性**: Gen 1-10连续无缺失
- [ ] **分数范围**: 所有分数在[0, 10]范围内
- [ ] **熵值范围**: Shannon熵在[0, log2(5)]范围内
- [ ] **分布求和**: model_distribution总和 = POPULATION_SIZE

### 3. 统计假设检验 ✅

**正态性检验**（Shapiro-Wilk）：
- [ ] 每组最终分数通过正态性检验（p>0.05），或
- [ ] 使用非参数替代方法（Mann-Whitney U）

**方差齐性检验**（Levene）：
- [ ] 组间方差齐性（p>0.05），或
- [ ] 使用Welch校正

**异常值检测**（Grubbs' Test / IQR方法）：
- [ ] 识别并记录异常值
- [ ] 敏感性分析（包含/排除异常值）

### 4. 结果合理性检查 ✅

**预期模式验证**（基于历史数据）：

- [ ] **DeepSeek组**（A, B）: 最终分数应在7.5-8.5范围
- [ ] **GLM4组**（C, D）: 最终分数应在6.8-7.8范围
- [ ] **5模型组**（E, F）: 最终分数应在6.5-7.5范围
- [ ] **多角色加成**: B>A, D>C, F>E（期望+0.1-0.3分）

**若结果偏离预期**：
- [ ] 检查随机种子是否正确设置
- [ ] 检查模拟参数是否合理
- [ ] 检查是否有外部干扰
- [ ] 考虑增加运行次数

## 常见问题排查（Troubleshooting）

### Q1: Ollama连接失败
```bash
# 检查服务状态
ollama serve

# 重启服务
pkill ollama
ollama serve
```

### Q2: 模型加载超时
```python
# 在代码中增加超时处理
try:
    response = ollama.chat(model=model, messages=messages, timeout=120)
except TimeoutError:
    # 重试或记录失败
    pass
```

### Q3: JSON解析错误
```python
# 使用try-except包装解析逻辑
import json
try:
    data = json.loads(raw_content)
except json.JSONDecodeError as e:
    print(f"JSON解析错误: {e}")
    # 记录原始内容用于调试
```

### Q4: 内存不足
```bash
# 减少并发数
# 修改代码中的max_workers参数
# 或在配置文件中设置
export OMP_NUM_THREADS=4
```
