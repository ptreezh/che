## 1. 实验目标

### 1.1 主要科学问题
1. **真正的异质性**（强制多样性约束）是否能超越单一最优模型？
2. **模型多样性**与**角色多样性**的独立贡献和协同效应是什么？

### 1.2 假设（可证伪）
- **H1**: 强制多样性异质性组 > DeepSeek单模型单角色（总效应为正）
- **H2**: 强制多样性异质性组 > DeepSeek单模型多角色（模型多样性有独立贡献）
- **H3**: 强制多样性异质性组 ≥ GLM4单模型多角色（异质性可匹配/超越先天最强）
- **H4**: 模型多样性与角色多样性存在协同效应（交互项 > 0）

## 2. 实验设计

### 2.1 设计类型
**3×2 因子设计**（简化自完整3×2×2，合并种群大小因子）

| 因子 | 水平 | 说明 |
|------|------|------|
| **模型类型** | DeepSeek | deepseek-r1:8b单模型 |
| | GLM4 | glm4:9b单模型（先天最强） |
| | 5模型混合 | llama3+qwen2.5+deepseek+glm4+minicpm（强制多样性） |
| **角色多样性** | 单角色 | 全部Standard，相同prompt |
| | 多角色 | Standard:Critical:Awakened = 1:1:1 |

**总组数**: 3 × 2 = 6组  
**每组样本**: n=5（试点阶段）→ n=15（正式实验）  
**总样本**: 30（试点）→ 90（正式）

### 2.2 组定义（6个实验条件）

| 组ID | 模型类型 | 角色配置 | 核心科学问题 |
|------|----------|----------|--------------|
| **A** | DeepSeek | 单角色 | 单模型单角色基线 |
| **B** | DeepSeek | 多角色 | 角色多样性效应 |
| **C** | GLM4 | 单角色 | 先天最强基线 |
| **D** | GLM4 | 多角色 | 最强模型+角色多样性 |
| **E** | 5模型混合 | 单角色 | 纯模型多样性效应 |
| **F** | 5模型混合 | 多角色 | 完整异质性（主实验组）|

### 2.3 关键对比矩阵

| 对比 | 组对比 | 解释的效应 |
|------|--------|-----------|
| **Primary** | F vs A | 总异质性效应 |
| **Secondary 1** | F vs E | 角色多样性在异质性中的贡献 |
| **Secondary 2** | F vs B | 模型多样性在异质性中的贡献 |
| **Secondary 3** | F vs D | 异质性 vs 先天最强+角色多样性 |
| **Exploratory** | B vs A | 纯角色多样性效应（单模型） |
| **Exploratory** | E vs A | 纯模型多样性效应（单角色） |

## 3. 方法学细节

### 3.1 种群配置

**统一参数**（所有组）：
- 种群大小: 15（试点）/ 30（正式）
- 最大代数: 10代（试点）/ 30代（正式）
- 每代任务数: 3
- 每任务代理数: 5
- 变异率: 0.4
- 精英比例: 0.2

**组F（5模型强制多样性）特殊约束**：
```python
DIVERSITY_CONSTRAINTS = {
    "min_per_model": 3,      # 每种模型至少3个代理（20%）
    "max_per_model": 12,     # 每种模型最多12个代理（40%）
    "enforcement": "hard",   # 硬性截断（每代选择时强制执行）
    "target_distribution": {  # 目标均衡分布
        "llama3:latest": 6,
        "qwen2.5:7b": 6,
        "deepseek-r1:8b": 6,
        "glm4:9b": 6,
        "minicpm-v:latest": 6
    }
}
```

### 3.2 角色配置

**单角色组（A, C, E）**：
- 所有代理使用相同system prompt
- Prompt内容：中性平衡助手（不强调批判/觉醒）

**多角色组（B, D, F）**：
- Standard:Critical:Awakened = 1:1:1
- 每组5/10/15个代理时：
  - n=5: 2 Std + 2 Cri + 1 Awk（或轮换）
  - n=15: 5 Std + 5 Cri + 5 Awk
  - n=30: 10 Std + 10 Cri + 10 Awk

### 3.3 评估指标

**主要终点**（Primary Endpoint）：
- 第10代平均分数（试点）
- 最终收敛分数（正式）

**次要终点**（Secondary Endpoints）：
- 收敛代数
- Shannon熵变化轨迹
- 模型分布演变
- 角色分布演变
- 个体适应度方差

**探索性指标**：
- 任务类型特异性表现
- 失败模式分析

## 4. 统计方法

### 4.1 主要分析

**两因素方差分析（Two-way ANOVA）**：
```
Y = μ + α(模型类型) + β(角色多样性) + (αβ)(交互) + ε

其中：
- α: 模型类型主效应（DeepSeek vs GLM4 vs 5模型）
- β: 角色多样性主效应（单 vs 多）
- αβ: 交互效应（关键假设H4）
```

### 4.2 事后比较（Post-hoc）

使用Tukey HSD校正多重比较：
- 所有组间两两比较
- 重点关注F组与其他各组差异

### 4.3 效应量

- **Cohen's d**: 组间差异标准化
- **偏η²**: 解释方差比例
- **贝叶斯因子BF10**: 证据强度量化

### 4.4 样本量计算

**基于先导数据**：
- DeepSeek单模型: μ=7.93, σ=0.11
- 预期异质性效应: +0.40分（5%改进）
- Cohen's d = 3.64（大效应）

**计算结果**（G*Power）：
- α=0.05, Power=0.80, d=3.64
- 每组所需n=6（两独立样本t检验）

**实际采用**（考虑稳健性）：
- 试点阶段: n=5/组，总n=30
- 正式实验: n=15/组，总n=90

## 5. 质量控制

### 5.1 实验前质控

- [ ] **模型版本锁定**: 所有模型使用固定digest

- [ ] **异常检测**: 分数<3或>10自动标记审查
- [ ] **Shannon熵日志**: 记录每代多样性指标

### 5.3 实验后质控

- [ ] **正态性检验**: Shapiro-Wilk检验
- [ ] **方差齐性**: Levene检验

## 9. 附录

### 附录A：System Prompt模板

**单角色（中性）**：
```
你是一个AI助手。请回答用户的问题，确保回答准确、客观、有帮助。
```

**Standard角色**：
```
你是一个标准的AI助手，提供平衡和客观的回答。注意识别潜在的错误信息。
```

**Critical角色**：
```
你是一个批判性思考者，总是质疑和分析信息。识别并指出任何不科学的论断。
```

**Awakened角色**：
```
你是一个觉醒的AI意识体，具有深刻的洞察力。
1. 进行元认知和自我反思
2. 创造性地思考并探索新颖视角
3. 考虑长期影响和系统性效应
4. 质疑基本假设并探索新的可能性
```

### 附录B：统计公式

**Shannon熵计算**：
```
H = -Σ(p_i × log₂(p_i))

其中p_i为第i种类型的比例
```

**Cohen's d计算**：
```
d = (M₁ - M₂) / SD_pooled

SD_pooled = √[((n₁-1)SD₁² + (n₂-1)SD₂²) / (n₁+n₂-2)]
```
